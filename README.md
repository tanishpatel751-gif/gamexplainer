<h1>GameXplainer</h1>
<h2>Overview</h2>

GameXplainer is a simple website that explains the rules and objectives of popular games. This project was created as my introduction to web development and is the first complete project I ever built from start to finish.

When I started learning HTML and CSS, I wanted to create something that would allow me to apply everything I had learned in a real project. A website explaining game rules was the best idea I could think of because it was straightforward, useful, and gave me opportunities to practice page layout, navigation, styling, images, and content organization.

Although the website is simple, it represents an important milestone in my programming journey because it was the first time I took knowledge from tutorials and turned it into a finished product.

<h2>My Learning Journey</h2>

This project combines concepts I learned through:

Khan Academy web development courses
YouTube HTML and CSS tutorials
Independent experimentation and practice

At the time I built this website, I had not yet learned JavaScript, so the entire project was created using only HTML and CSS.

Looking back, this project helped me understand how websites are structured and gave me the confidence to move on to more advanced technologies and larger software projects.
